# Pilotspan — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Executive sponsor

- As a sponsor, I want a single portfolio view of pilots, so that I stop funding duplicate department experiments.
- As a sponsor, I want kill recommendations with evidence, so that sunk-cost pilots end cleanly.

### Pilot product owner

- As a pilot owner, I want a charter template tied to APMF steps, so that I know what “ready to start” means.
- As a pilot owner, I want anonymisation gate results before data access, so that privacy review is not a surprise at demo day.
- As a pilot owner, I want real-world success metrics registered, so that training accuracy cannot fake graduation.

### Data custodian

- As a data custodian, I want to approve or reject dataset use per pilot, so that excess employee access shrinks.
- As a data custodian, I want quality issues logged against datasets, so that 80% prep-time waste becomes visible.

### Privacy / ethics reviewer

- As an ethics reviewer, I want five-point anonymisation scoring, so that Aggregate-through-Hash is not optional folklore.
- As an ethics reviewer, I want correlated-feature bias notes captured, so that zip-code proxies are discussed before launch.

### Talent partner

- As a talent partner, I want ATF role assignments on each pilot, so that we develop internal capability instead of only hiring contractors.
- As a talent partner, I want domain specialists bookable for one-hour consults, so that dream teams are realistic.
